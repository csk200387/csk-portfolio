# about

AI·빅데이터공학을 전공하며 데이터의 신뢰성과 시각화에 집중하고 있습니다. 원시 데이터가 의사결정에 쓰이기까지의 과정—수집, 정제, 검증, 시각화—중에서도 특히 데이터 품질 검증과 개인정보를 다루는 방식에 관심이 있습니다.

## local-first

만든 도구는 대부분 사용자의 데이터를 서버로 보내지 않고 브라우저 안에서 처리합니다. 누구나 자신의 데이터를 안전하게 들여다볼 수 있도록.

## focus

- **데이터 품질** 결측치·이상치·스키마 검증
- **프라이버시** 로컬 우선 처리, 서버 미전송
- **시각화** 탐색적 데이터 대시보드
- **웹 도구** 빌드 없는 정적 배포
